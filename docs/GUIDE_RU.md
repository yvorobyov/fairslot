# Инструкция для организатора

## 1. Подготовь четыре таблицы (CSV)

Выгрузи из Google Таблиц или Excel как CSV либо введи прямо на странице.

**Слоты** (`id,start,end,resource,levels`)
```
id,start,end,resource,levels
fri-1930-c1,2026-11-20T19:30,2026-11-20T21:00,court1,
```
`id` любой уникальный текст. `start` в формате `ГГГГ-ММ-ДДTЧЧ:ММ`, местное время. `levels` необязательно: уровни, допущенные на этот слот, например `D;D+`.

**Участники** (`id,level`)
```
id,level
Anna,D
Borys,C+
```
Короткое имя или ник. Уровни должны совпадать с названиями в профиле.

**Заявки** (`id,slot,members,open,avoid,want,ts`)
```
id,slot,members,open,avoid,want,ts
a1,fri-1930-c1,Anna|Filip,yes,,,2026-11-18T09:00
```
* `members`: все в команде через `|`. Одно имя значит заявку в одиночку.
* `open`: `yes`, если свободные места могут занять другие заявители.
* `avoid`: кого не ставить в группу. `want`: с кем хочется играть.
* `ts`: время подачи заявки. По нему упорядочиваются равные случаи и считается недельный лимит заявок.

**История** (необязательно, `member,start,result`)
```
member,start,result
Borys,2026-11-12T20:00,lost
```
`result`: `won`, `played` или `lost`. Без истории у всех одинаковый вес.

Несколько значений в одной ячейке разделяй знаком `|` или `;`. Если твой Excel разделяет столбцы знаком `;`, внутри ячеек используй `|`.

## 2. Выбери правила

Возьми готовый профиль и при необходимости поменяй отдельные настройки. Описание: [PROFILES.md](PROFILES.md), [SETTINGS.md](SETTINGS.md).

## 3. Объяви зерно

До конца приёма заявок объяви публичное зерно: число из открытого источника или фразу в общем чате. После этого его не меняет никто, включая тебя.

## 4. Проведи розыгрыш

В браузере: открой `fairslot.html`, вставь или перетащи таблицы, введи зерно и время розыгрыша, нажми «Провести розыгрыш».
В командной строке: см. README.

Слоты дальше, чем `draw_hours_before`, пропускаются и помечаются как «ещё рано».

## 5. Прочитай результат

У каждого слота видны группа, хозяин слота, свободные места и лист ожидания. Если ты задал шаблон ссылки, у каждой группы появится готовая ссылка на бронь. Поля шаблона: `{date}`, `{time}`, `{resource}`, `{owner}`, `{members}`, `{slot_id}`, `{start}`. Пример: `https://calendly.com/you/court?date={date}&time={time}&name={owner}`.

Отправь ссылку хозяину слота: последнюю кнопку нажимает он. fairslot сам ничего не бронирует.

## 6. Опубликуй и дай проверить

Нажми «Скачать result.json» (или «Копировать JSON») и выложи файл рядом с объявлением. Любой открывает вкладку «Проверка», вставляет файл и видит «проверено» либо первое расхождение. В файле только идентификаторы, веса и ключи.

## 7. После розыгрыша

* Хозяин просит заменить игрока: проверь замену функцией `fairslot.substitution.check_swap` (Python) или реши по правилу профиля.
* Места всё ещё свободны перед игрой: `market_seats` покажет их для «кто первый», `claim_seat` проверит уровень и «не ставить с».
